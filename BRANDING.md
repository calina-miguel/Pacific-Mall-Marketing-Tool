# Pacific Mall Marketing Tool — Brand & Style Guidelines

## 1. Brand Name Spelling
- **Always write "Pacific Mall" with a space between "Pacific" and "Mall"**.
- Never combine them as "PacificMall" in user-visible UI, headers, modals, or captions (hashtags excepted).
- In JSX code with split styling: use `Pacific{' '}<span ...>Mall</span>` to ensure the space is permanent and cannot be stripped by code formatters or minifiers.

## 2. Color Palette (Extracted from Official Logo)
- **Primary / Dominant:** Royal Purple (`#321c65`)
- **Accent / Highlight:** Magenta / Fuchsia (`#b60090`)
- **Status / Success:** Emerald Green (`#26aa00`)
- **Background:** Soft Cool Gray (`#f7f6fa`)
- **Card Background:** Pure White (`#ffffff`) with subtle purple border (`rgba(50, 28, 101, 0.08)`)

## 3. UI/UX Aesthetic
- Follows the AdScale design system: rounded pill badges, 24px card corner radiuses, clean sans-serif typography, and subtle box shadows.
- No visible AI / LLM branding anywhere in the UI.
